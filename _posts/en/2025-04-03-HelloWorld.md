This technical blog used to run on WordPress. Because of work it fell out of
maintenance for a long time, so I recently moved it to Jekyll and publish it
through GitHub Pages.

1. Fork a Jekyll template.
2. Build and serve it locally.

````
bundle exec jekyll build

bundle exec jekyll serve
````
